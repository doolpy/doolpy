# 고스톱 점수판

한국어 고스톱 점수 계산기입니다. 한 화면에서 각 플레이어의 광·열끗·띠·피를 동시에 입력하고, 이번 점수와 적용 배수를 확인한 뒤 판을 함께 마감해 플레이어별 누적 점수에 기록할 수 있습니다. 5판마다 최근 5판의 점수를 인원수에 맞춰 정산하고 송금할 점수 차이를 보여줍니다.

## 실행

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 여세요. 점수 계산 로직 테스트는 `npm test`로 실행합니다.

## iPad 홈 화면 앱 및 오프라인 사용

```sh
npm run build:pwa
```

정적 배포용 파일이 `pwa-dist` 폴더에 만들어집니다. 이 저장소는 GitHub Pages 프로젝트 주소(`https://doolpy.github.io/doolpy/`)를 지원하도록 상대 경로를 사용합니다. `.github/workflows/deploy-pages.yml` 워크플로를 기본 브랜치에 반영하고 저장소 Settings → Pages에서 **GitHub Actions**를 배포 소스로 선택하면, 이후 기본 브랜치에 반영할 때 자동 배포됩니다. 배포한 HTTPS 주소를 iPad Chrome에서 한 번 열면 점수 기록과 오프라인 캐시를 사용할 수 있습니다. 홈 화면 설치를 제공하는 브라우저에서는 공유 메뉴의 **홈 화면에 추가**를 사용할 수 있습니다. 첫 접속에는 HTTPS 연결이 필요하며, GitHub Pages 공개 배포는 App Store 앱 배포와 다릅니다.

점수 기록은 해당 HTTPS 주소에 연결된 이 iPad의 브라우저 저장 공간에 보관되며 기기간 동기화되지 않습니다. 개인 정보 보호 브라우징에서는 저장이 유지되지 않을 수 있습니다. 앱 상단의 설치 안내에서도 단계를 확인할 수 있습니다.

## 오프라인 iPad 파일 만들기

```sh
npm run build:offline
```

프로젝트 폴더에 생성되는 `고스톱-점수판-오프라인.html`은 CSS와 JavaScript를 한 파일에 포함하므로 인터넷 없이 실행할 수 있습니다. iPad에서는 파일 앱의 공유 메뉴에서 Chrome으로 여세요. `pwa-dist` 안의 `index.html`을 따로 저장해 직접 열면 안 됩니다. 점수는 같은 파일을 연 Chrome 저장 공간에 보관되지만, iOS 브라우저가 로컬 파일 저장을 제한할 수 있습니다. 다시 열었을 때 기록이 유지되지 않거나 자동 저장 안내가 표시되면, `pwa-dist`를 HTTPS 주소에 배포해 Chrome에서 한 번 연 뒤 사용하세요. 브라우저나 파일을 바꾸면 기록이 이어지지 않을 수 있습니다.

## 점수 기준

- 광: 3광 3점, 4광 4점, 5광 15점. 비광을 포함한 3광을 2점으로 세는 규칙은 선택할 수 있습니다.
- 열끗과 띠: 각 5장부터 1점, 기준을 넘는 한 장마다 1점씩 더합니다.
- 피: 10장부터 1점이며 쌍피는 두 장으로 셉니다.
- 멍따: 기본 선택 상태이며 열끗 7장부터 2배를 적용합니다.
- 고: 기본 선택 상태이며 3고부터 두 배씩 적용합니다(3고 ×2, 4고 ×4).

모임마다 규칙이 다를 수 있어 배수와 비광 포함 3광 규칙을 바꿀 수 있습니다. 박·흔들기·피박·광박과 점당 금액 환산은 계산하지 않습니다. 점수는 브라우저에 자동 저장되며, 마지막 판은 모든 플레이어 기록과 입력을 함께 되돌릴 수 있습니다. 전체 초기화와 플레이어 삭제는 확인 후 진행합니다.

플레이어별 입력은 한 화면에 모두 표시됩니다. 각자 패 수와 계산 결과를 확인하고 화면 아래의 **이번 판 기록하기**를 한 번 눌러 함께 기록합니다. 상단의 **점수 로그 보기**에서 전체 과거 기록으로 이동할 수 있으며, 각 기록을 펼쳐 날짜, 입력 패, 카테고리별 점수와 적용 배수를 확인합니다. 정산은 점수 단위로 표시하며, 실제 금액은 모임에서 정한 점당 금액을 적용하세요. 정산 잔여점수는 해당 5판에서 더 많은 점수를 얻은 플레이어부터 균등 몫에 1점을 더하는 방식으로 계산합니다.
